# แบบฟอร์มกรอกข้อมูลครอบครัว

กรอกข้อมูลลงไฟล์ CSV ตามลำดับหมายเลข แล้วส่งกลับมาให้ Claude แปลงเป็น
insert script ลง Supabase ได้เลย **แถวตัวอย่างที่ใส่ไว้ให้ ลบทิ้งแล้วแทนที่
ด้วยข้อมูลจริง**

การอ้างอิงระหว่างไฟล์ใช้ *ชื่อ* (ไม่ใช่ id): `owner_name` ต้องตรงกับ
`display_name` ในไฟล์ 1 และ `property_name` ต้องตรงกับไฟล์ 2 ทุกตัวอักษร

## 1_landlords.csv — สมาชิกครอบครัว (เจ้าของห้อง)

| คอลัมน์ | จำเป็น | ความหมาย |
|---|---|---|
| `display_name` | ✔ | ชื่อเรียกในแดชบอร์ด เช่น แม่ / พี่ปอ |

LINE user ID ไม่ต้องกรอก — ระบบจะผูกให้เองเมื่อแต่ละคนทักบอทครั้งแรก

## 2_properties.csv — คอนโดแต่ละห้อง

| คอลัมน์ | จำเป็น | ความหมาย |
|---|---|---|
| `owner_name` | ✔ | ต้องตรงกับ `display_name` ในไฟล์ 1 |
| `property_name` | ✔ | ชื่อห้องที่จะแสดงในแดชบอร์ด (ต้องไม่ซ้ำกัน) |
| `floor_level` | | ชั้น |
| `unit_no` | | เลขห้อง |
| `size (square meter)` | | ขนาดห้อง (ตร.ม.) |
| `purchase_price` | | ราคาซื้อ (บาท) — ใช้คำนวณ yield |
| `rental aim` | | ค่าเช่าเป้าหมายต่อเดือน (บาท) |

ไฟล์นี้เป็น *แหล่งข้อมูลจริง* ของข้อมูลห้อง — รัน import ซ้ำจะอัปเดตห้องเดิม
ให้ตรงกับ CSV (เจ้าของ, ชั้น, ขนาด, ราคา) โดยไม่สร้างแถวซ้ำ

## 3_leases.csv — สัญญาเช่าที่กำลังดำเนินอยู่

ห้องที่ว่างอยู่ไม่ต้องมีแถวในไฟล์นี้

| คอลัมน์ | จำเป็น | ความหมาย |
|---|---|---|
| `property_name` | ✔ | ต้องตรงกับไฟล์ 2 |
| `tenant_name` | ✔ | ชื่อผู้เช่า |
| `rent_amount` | ✔ | ค่าเช่า/เดือน (บาท) |
| `deposit_amount` | | เงินมัดจำ |
| `due_day` | ✔ | วันครบกำหนดชำระ (1–28) |
| `billing_type` | ✔ | `fixed` (ค่าเช่าอย่างเดียว) หรือ `rent_plus_utilities` |
| `start_date` / `end_date` | ✔ | วันเริ่ม/สิ้นสุดสัญญา รูปแบบ `YYYY-MM-DD` (ค.ศ.) |
| `expected_payer_name` | | ชื่อบัญชีผู้โอน (ช่วยให้จับคู่สลิปแม่นขึ้น) |

## 4_transactions.csv — รายรับ-รายจ่ายย้อนหลัง

| คอลัมน์ | จำเป็น | ความหมาย |
|---|---|---|
| `owner_name` | ✔ | ต้องตรงกับไฟล์ 1 |
| `property_name` | ✔ | ต้องตรงกับไฟล์ 2 |
| `date` | ✔ | `YYYY-MM-DD` (ค.ศ.) — ถ้ารู้แค่เดือน ใช้วันที่ 1 ของเดือนนั้น |
| `direction` | ✔ | `in` = รายรับ, `out` = รายจ่าย |
| `category` | ✔ | หนึ่งใน: `rent`, `common_fee`, `agency`, `maintenance`, `tax`, `utilities`, `insurance`, `other` |
| `amount` | ✔ | จำนวนเงิน (บาท, ตัวเลขบวกเสมอ — ฝั่งรับ/จ่ายดูจาก `direction`) |
| `note` | | บันทึกช่วยจำ |

## เปิดไฟล์ด้วย Excel

ไฟล์บันทึกเป็น UTF-8 (มี BOM) เปิดกับ Excel ได้เลย ภาษาไทยไม่เพี้ยน —
ตอนบันทึกให้เลือก **CSV UTF-8** เท่านั้น
