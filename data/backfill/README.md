# กรอกรายการย้อนหลัง (ช่วงที่บอทปิดอยู่)

ไฟล์: `transactions_backfill.csv` — ข้อมูลในระบบหยุดอยู่ที่ประมาณ **9 ก.ค. 2026**
ให้กรอกรายรับ-รายจ่ายทุกรายการที่เกิดขึ้นหลังจากนั้น แล้วแจ้ง Claude ให้นำเข้า
(จะมีขั้นตอน dry-run ให้ตรวจยอดก่อนเขียนลงฐานข้อมูลจริง)

## คอลัมน์

| คอลัมน์ | จำเป็น | ความหมาย |
|---|---|---|
| `property_name` | | ชื่อคอนโด ต้องตรงกับรายชื่อด้านล่างทุกตัวอักษร — **เว้นว่าง = รายการของกองกลาง** |
| `date` | ✔ | วันที่โอน/จ่ายจริง รูปแบบ `YYYY-MM-DD` (ค.ศ.) เช่น `2026-08-21` |
| `direction` | ✔ | `in` = รายรับ, `out` = รายจ่าย |
| `category` | ✔ | หนึ่งใน: `rent`, `deposit`, `common_fee`, `agency`, `maintenance`, `tax`, `utilities`, `insurance`, `other` |
| `amount` | ✔ | จำนวนเงิน (บาท) เป็นเลขบวกเสมอ ไม่ต้องใส่ลูกน้ำ |
| `rent_month` | เฉพาะค่าเช่า | เลขเดือน 1–12 ที่ค่าเช่านี้จ่ายให้ เช่น `8` = ค่าเช่าเดือนสิงหาคม — ระบบจะใช้ปิดบิลเดือนนั้น (ไม่กรอก = บันทึกเป็นรายรับเฉย ๆ บิลยังค้างอยู่) |
| `note` | | บันทึกช่วยจำ |

เจ้าของห้องไม่ต้องกรอก — ระบบดูจากชื่อคอนโดให้เอง

## แถวที่เตรียมไว้ให้แล้ว

8 แถวแรกคือ **ค่าเช่าที่ระบบยังเห็นว่าค้างชำระ** (ยอดตามสัญญา ยังไม่มีวันที่):

- ผู้เช่าจ่ายแล้ว → ใส่ `date` (และแก้ `amount` ถ้ายอดจริงไม่ตรง)
- จ่ายบางส่วน → แก้ `amount` เป็นยอดที่ได้รับจริง
- ยังไม่ได้จ่าย → **ลบแถวนั้นทิ้ง**

จากนั้นเพิ่มแถวใหม่สำหรับรายการอื่น ๆ (ค่าส่วนกลาง ค่าซ่อม ค่าน้ำไฟ ฯลฯ) ได้ไม่จำกัด
